# DeepSeek Studio

> **The mobile IDE that builds, signs, and publishes Android apps from your phone.**

DeepSeek Studio is an AI-powered code editor that runs entirely inside Termux on Android. It combines a real filesystem, a real shell, a real editor (Monaco — the engine behind VS Code), and an AI agent that writes, tests, and ships code — all from your pocket.
