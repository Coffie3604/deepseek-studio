You're in the DeepSeek Studio app. The app is a native shell — it needs the Termux backend running on 127.0.0.1:3001 to work.

Do this:

    curl -fsSL https://raw.githubusercontent.com/Coffie3604/deepseek-studio/main/install.sh | bash

First-time setup Install Termux + the companion apps

You need three things installed from F-Droid. Don't use Play Store versions — signatures won't match.

1. Termux

The terminal environment that runs the backend.

Get Termux from F-Droid ~130 MB, required

2. Termux:API

Enables wake-lock (prevents Android killing the server) and notifications.

Get Termux:API from F-Droid ~180 KB, strongly recommended

3. Termux:Widget

Adds home-screen shortcuts for one-tap launch.

Get Termux:Widget from F-Droid ~100 KB, optional but great

Install the backend

Once Termux is open, paste this:

curl -fsSL https://raw.githubusercontent.com/Coffie3604/deepseek-studio/main/install.sh | bash

Takes 2–4 minutes. It clones the repo, installs Node.js and npm dependencies, and creates the ds-* commands.

Daily commands The ds-* shortcuts
Command What it does
ds-startBoot the backend and open Chrome
ds-stopKill the server, save battery
ds-restartFull restart (use when things act weird)
ds-statusShow version, uptime, PID
ds-logTail the live server log (Ctrl+C to exit)
ds-updatePull latest code + reinstall dependencies

Home screen widgets

  3. Pick 🚀 DeepSeek, 🛑 Stop, 🔄 Restart or ℹ️ Status
What's in the app Chat, editor, terminal, sidebars

Three main tabs

  • Chat — describe what you want built. Type / for prompt templates.
  • Editor — Monaco (the VS Code engine) with tabs, find/replace, formatting.
  • Terminal — full Termux shell. AI commands appear in real-time.

Troubleshooting Common problems and fixes
SymptomFix
This page keeps appearing Open Termux and run ds-start
"Cannot GET /api/…" Run ds-update && ds-restart
Server hangs on startup Run ds-log in Termux, look for errors
Wake-lock missing in log Install Termux:API app, open it once
Notifications don't fire Same as above — needs Termux:API app installed
Widget does nothing Open Termux once manually, then retry the widget
AI says "add key" In app: Setup → paste API key
Chat is slow / frozen Check ds-log. Look for repeated API errors.
