DeepSeek Studio

AI-powered code editor that runs entirely on your Android phone.

🚀 Quick Start

  1. Install Termux from F-Droid
  2. Run the installer in Termux:
    curl -fsSL https://raw.githubusercontent.com/Coffie3604/deepseek-studio/main/install.sh | bash
  3. Install Termux:Widget from F-Droid
  4. Long-press home screen → Widgets → Termux:Widget → add the 4 shortcuts
  5. Tap 🐳 DeepSeek Start
  6. In Chrome, open Setup → paste your AI key

📱 The 4 Home Screen Widgets

WidgetActionWhen to use
🐳 StartBoot server + open ChromeEvery session start
🛑 StopKill server, save batteryEnd of session
🔄 RestartFull restart + reopenIf misbehaving
ℹ️ StatusToast shows version + uptimeCheck health

🖥️ The Three Tabs

💬 Chat

Pick a project, describe what you want. The AI writes files, runs commands, fixes bugs. Type / for snippet templates.

📝 Editor

Monaco (VS Code engine) with multi-tab, find/replace, format. Tap Save ▾ in the header for the full menu (Save As, Reload, Find, Format, Bookmark).

💻 Terminal

Full Termux shell. AI commands appear here in real-time with # AI: prefix. Use Ctrl+C to interrupt, Kill to force-stop.

💡 Pro Tips

  • Type / in chat for 12 pre-built prompt templates
  • Enable Auto to let AI run tools without confirmation
  • Click any command in AI response → runs in terminal
  • Click any file.py in AI response → opens in editor
  • Ctrl+S saves, Ctrl+W closes tab
  • Long-press files for rename/delete/copy-path
